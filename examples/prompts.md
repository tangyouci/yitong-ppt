# Prompt examples

## Academic reports

```text
Use $yitong-ppt to turn this paper into a 15-minute group-meeting presentation. Explain the motivation, method, experiments, limitations, and one follow-up idea. Deliver an editable PPTX.
```

```text
Use $yitong-ppt to create a tutorial on vision-language models for an audience that knows basic deep learning but not this field. Build the taxonomy first, then representative methods and open problems.
```

## Project reports

```text
Use $yitong-ppt to turn this month's project notes, metrics, and screenshots into a 10-page leadership update. Separate achieved results, targets, risks, and next decisions.
```

```text
Use $yitong-ppt to redesign this engineering review deck. Keep the existing brand master, reduce text, make the system architecture editable, and verify every metric against the attached report.
```

## Image-first option

```text
Use $yitong-ppt to create the deck end to end. For the architecture and key result pages, explore the complete-slide visual direction first, then reconstruct the approved direction as editable PowerPoint without pausing for routine confirmation.
```
